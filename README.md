# 🏅 Olympic Games Data Analysis and Prediction System

This project analyzes 120 years of Olympic Games data using Python and machine learning techniques to uncover insights, visualize trends, and predict future performance.

---

## 📌 Features

- 📊 **Country-wise Performance Tracking**
- 🧑‍🤝‍🧑 **Athlete Trend Analysis**
- 🤖 **Medal Prediction using Machine Learning**
- 📈 **Interactive Data Visualizations (Seaborn, Plotly, Tableau)**
- 🌐 **Web-based Dashboard using Streamlit & HTML**
- 💾 **MongoDB Integration for Data Storage**
- 🗳️ **User Engagement through Voting**

---

## 🛠️ Technologies Used

| Layer          | Technologies                             |
|----------------|-------------------------------------------|
| **Frontend**   | HTML, CSS, Bootstrap, JavaScript, React.js |
| **Backend**    | Python (Streamlit), Node.js, Express.js   |
| **Database**   | MongoDB, Mongoose                         |
| **ML Tools**   | pandas, seaborn, matplotlib |
| **Visualization** | Plotly, Tableau, Streamlit              |
| **Hosting**    | GitHub Pages / Streamlit Cloud            |
